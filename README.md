Este repositório é sobre o exercício de IA da professora Érica, realizado em grupo.

Esse é apenas o código, e a documentação do projeto é um arquivo .docs, que até o momento não estará presente no repositório.

Observação: Para fins didáticos e do meu aprendizado, esse projeto possuirá um requirements.txt, porém para rodar o projeto é necessário possuir uma interface TKINTER instalada na sua instalação do python (ou python3), ou seja, não é possível instalar todas as dependências do projeto somente com o requirements.txt

E, como o obetivo do nosso repositório é manter o código o mais portável possível e rodá-lo em um ambiente virtual venv, estarei atualizando o código em sequência para que as imagens geradas pelo gráfico sejam salvas dentro do arquivo e não abertas automaticamente.
